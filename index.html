Documentação do Projeto OLED & LED

Bem-vindo à página de especificações do projeto de monitoramento simulado.

Componentes Simulados

  • Display OLED: Tela monocromática com emissão de luz por contraste para alta visibilidade.
  • LED Indicador: Diodo emissor de luz usado para indicar estado de energia do circuito.

Como Funciona

O script no arquivo principal alterna o estado lógico do sistema simulado entre ligado e desligado, alterando a renderização CSS do LED e do display OLED.
